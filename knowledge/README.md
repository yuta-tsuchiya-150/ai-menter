# ナレッジベース (Knowledge Base)

本ディレクトリは、コードベースの調査結果、設計メモ、技術的分析、運用手順などのナレッジをMarkdown形式で蓄積・共有するためのフォルダです。
複数のPC環境（自宅PC間など）からシームレスに情報共有・開発を進められるように管理します。

## 命名規則・配置ルール
- 原則として、日付やトピックが明確に分かるファイル名（例: `YYYY-MM-DD_<テーマ>.md`）で配置します。
- 分析・調査を行った際は、チャット画面への提示に加えて必ず本フォルダ配下にMarkdownファイルを生成・更新します。
- 生成・更新されたファイルは、GitHubへプッシュして常にリモートと同期します。
