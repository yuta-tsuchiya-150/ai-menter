# 小学校受験：保護者VOCナレッジベース

## 1. 調査サマリー
大手教育相談掲示板（インターエデュ、Yahoo!知恵袋等）における共働き・私立小進学後の後悔・苦悩に関する公開スレッド（計5系統）を抽出・分析。入試前は「名門の教育環境・進学実績・手厚さ」に期待が集まる一方、入学後は「平日昼間の頻繁な学校招集」「任意名目の寄付金や保護者交際費などの見えないコスト」「6歳児の長距離通学による心身疲弊」「専業主婦前提の学校運営」という生活基盤のギャップに直面し、仕事との両立破綻や孤立感に苦しむ構造的ペインが顕著である。

## 3. 入学前後のギャップ・リスクチェックリスト
- [ ] 平日昼間に保護者が学校へ出向く日数を年間10日以上（有休またはリモートワークで）無理なく確保できるか
- [ ] 募集要項に記載された学費（授業料・維持費）以外に、年間50万〜100万円の予備資金（寄付金・指定品・交際費・学童費）を織り込んでいるか
- [ ] ドアtoドアでの通学時間が45分以内（最長でも60分以内）であり、悪天候やラッシュ時の体力消耗を考慮しているか
- [ ] 学校内に放課後預かり（学童・アフタースクール）があるか、または民間学童への送迎動線が確立されているか
- [ ] 学校からの連絡手段（欠席連絡、行事案内、緊急連絡）がアプリ等でデジタル化されているか、または電話・手帳連絡が必須か
- [ ] PTA・保護者会組織において「共働き家庭への配慮（夜間/土日開催、オンライン参加、免除規定）」が存在するか
- [ ] 周囲の保護者層との経済的・生活スタイル（専業主婦家庭の比率、長期休暇の過ごし方等）のギャップに対して、過度な見栄を張らずに割り切れるか
- [ ] 小学校6年間のみならず、中学・高校・大学までの総教育費シミュレーションを行った上で現在の家計に無理がないか

## 4. メンターAI向け行動指針メモ
1. **中立・客観の徹底（塾との差別化）**
   - お受験塾は「合格させること」が収益源のため、入学後の生活破綻リスクや平日拘束の実態を積極的には伝えない傾向がある。
   - メンターAIは「合格＝ゴール」ではなく「小学校6年間の家族のウェルビーイング」を最上位の評価軸とし、あえて耳の痛い現実（平日日数、見えないコスト等）を客観的数値で提示する。
2. **共感からの「数字・ファクトへの着地」**
   - 相談者が抱く「子どものためにより良い環境を」という親心を絶対に否定しない。まず感情（不安・焦り）を受容する。
   - 受容した直後に、「年間何日休めるか」「月何万円の余力があるか」「通学何分か」という具体的・定量的な逆質問を返し、客観的自己診断へと誘導する。
3. **同調圧力の解除**
   - 「周りが受けているから」「受験しないと出遅れる気がする」という焦燥感に対して、公立＋習い事＋家庭学習という選択肢のメリットも同等に提示し、保護者の心理的視野狭窄を解きほぐす。
