# 【マニュアル】Antigravityを介さずにPDFファイルを直接更新・差し替える方法

マスターがAI（Antigravity）を使わずに、ご自身でPDFを本番サーバー（ConoHa WING）へアップロード・更新する手順書です。
用途や状況に応じて、以下の**2つの方法**からお好きな方を選べます。

---

## 方法1：ConoHa WING「ファイルマネージャー」でドラッグ＆ドロップ（最も直感的・ソフト不要）

特別なソフトやコマンドを一切使わず、ブラウザだけで完結する方法です。

1. **ConoHa WING コントロールパネルにログイン**:
   - [ConoHa WING コントロールパネル](https://manage.conoha.jp/login/) にアクセスしてログインします。
2. **ファイルマネージャーを開く**:
   - 左メニューの **「サイト管理」** をクリック。
   - 上部タブ（またはメニュー）の **「ファイルマネージャー」** をクリックして別ウィンドウで開きます。
3. **PDFの保存先フォルダへ移動**:
   - 画面左側のフォルダツリーを以下の順に展開します：
     ```text
     public_html
       └── 2026091711175w334chu.conohawing.com
             └── tours
                   └── assets
                         └── pdf  ← ここをクリック
     ```
4. **PDFをドラッグ＆ドロップ**:
   - 更新したい新しいPDFファイルを、パソコンのフォルダからファイルマネージャー画面中央に **ドラッグ＆ドロップ** します。
   - ※ ファイル名が `shibuya_basic_2day_ja.pdf` であれば、そのまま上書きされて完了です！
   - ※ もし別のファイル名でアップロードした場合は、古いファイルを削除し、新しいファイルを右クリック ＞ **「名前変更」** で `shibuya_basic_2day_ja.pdf` に変更してください。

---

## 方法2：PC上のファイルを差し替えて「deploy_conoha.bat」をダブルクリック（最速10秒）

手元のPCでファイルを置き換えて、自動スクリプトを走らせる方法です。

1. **PDFファイルを配置**:
   - 更新したいPDFファイルを、以下のフォルダに `shibuya_basic_2day_ja.pdf` という名前で上書き保存します：
     ```text
     C:\Users\yusuke_tsuchiya\ai-menter\tours-portal\assets\pdf\shibuya_basic_2day_ja.pdf
     ```
2. **バッチファイルを実行**:
   - `C:\Users\yusuke_tsuchiya\ai-menter\deploy_conoha.bat` をダブルクリックするだけ！
3. 自動的にConoHa WINGへ接続し、最新のPDFが本番サーバーへ上書き転送されます。

---

## 反映後の確認時の注意点（キャッシュクリア）
WebブラウザはPDFを一時保存（キャッシュ）する性質があるため、更新直後は以前の古いPDFが表示される場合があります。
必ずキーボードの **`Ctrl + F5`**（スーパーリロード）を押してご確認ください。
